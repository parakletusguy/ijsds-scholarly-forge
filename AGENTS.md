# IJSDS newsletter work

For any request to draft, edit, design, or prepare an IJSDS newsletter, digest, call for papers, author spotlight, paper roundup, editorial note, or newsletter blog post, use the installed `ijsds-newsletter` skill. Its brand, privacy, output, and review requirements apply unless the user explicitly directs otherwise.

## IJSDS delivery accounts

Use the Google Drive and Gmail connectors authenticated as `editor.ijsds@gmail.com` for IJSDS newsletter work. Read the mailing list from the connected Drive only as needed to prepare recipients; do not expose addresses or other personal data in chat. Create newsletter drafts in the connected Gmail account, but never send them without an explicit instruction in the same message.
